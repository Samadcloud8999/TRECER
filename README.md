# Карман — расходы, накопления и места

React + JavaScript, Vite, React Router, Framer Motion, Three.js, Recharts, Leaflet, IndexedDB. Интерфейс на русском; валюта — кыргызский сом; время — Asia/Bishkek (UTC+6). Это личный дневник, не подключение к реальному банковскому счёту.

## Быстрый запуск

1. Установи Node.js 22 LTS или новее.
2. Распакуй ZIP и открой терминал в папке `pocket`.
3. Выполни `npm ci`, затем `npm run dev`.
4. Открой адрес, который показан в терминале. Для доступа с телефона используй HTTPS-публикацию на Vercel.

Production: `npm run build`. Проверка готовой сборки: `npm run preview`.

## Загрузка на Vercel

1. Создай пустой репозиторий GitHub и загрузи содержимое папки `pocket` (package.json должен быть в корне выбранного проекта). Не загружай node_modules.
2. В Vercel: Add New → Project → импортируй репозиторий.
3. Framework: Vite. Install: `npm ci`. Build: `npm run build`. Output: `dist`.
4. Нажми Deploy. Встроенный vercel.json уже содержит обработку React Router: обновление страниц `/expenses`, `/places`, `/events` не должно выдавать 404. Пути `/api/*` не перенаправляются на index.html.
5. Открой HTTPS-ссылку на телефоне. При запросе разреши доступ к местоположению и уведомлениям.

Базовые возможности работают без переменных окружения. Приложение не опубликовано от твоего имени: ZIP готов для самостоятельной загрузки.

## Возможности

- Обзор: расходы сегодня, расходы месяца, накопления, итог дня и график последних семи дней.
- Расходы: ввод только суммы допускается; название необязательно, по умолчанию «Покупка». Поддерживается десятичная запятая. Категория, дата, время, фото и геопозиция. Поиск и фильтры; изменение и удаление с подтверждением. Круговой график категорий.
- Накопления: сумма внесённых пополнений, дневной итог, история и изменяемая цель. Пополнения не смешиваются с покупками.
- Фото: камера телефона или выбор файла до 20 МБ. Фото сохраняется в IndexedDB. Камера на ПК может открыть обычный выбор файла — это зависит от браузера.
- Геопозиция: текущая GPS-точка с точностью и временем фиксации, повторное определение, ручной ввод координат. При выборе фото запрашивается текущее местоположение. EXIF старых фото не читается: для старого снимка укажи место вручную. Координаты — момент записи, а не доказательство места съёмки.
- Места: отдельная фотогалерея любимых мест; изменение названия, фото и точки.
- Карта OpenStreetMap: маркеры покупок с фото и любимых мест, фильтры «Все фото / Покупки / Любимые места», карточки и просмотр фото. Фото без точки остаётся в дневнике, но маркер не создаётся.
- Погода Бишкека: текущая температура и ветер, ближайшие шесть часов с вероятностью осадков, пять дней. Данные Open-Meteo, обновление каждые 30 минут и вручную; реальные данные, без подставного прогноза. Интернет обязателен.
- События: дата, время, собственный текст, повтор ежедневно или один раз, включение/выключение, редактирование, своя мелодия до 10 МБ, проверка звука.
- Резервная копия JSON включает записи, фото, аудио и настройки. Восстановление заменяет текущий дневник после подтверждения; файл проверяется до замены данных.
- Адаптивная мобильная навигация, анимации с учётом reduced-motion, WebGL-объекты в карточке расходов и накоплений. Если WebGL недоступен, карточки сохраняют функциональность.
- Manifest и service worker позволяют установку приложения на поддерживаемых устройствах. Полное офлайн-кэширование приложения не включено.

## Как работают напоминания — прочитай перед использованием

**Без серверной настройки:** пока приложение открыто, оно проверяет время каждые две секунды. После разрешения браузера показывается системное уведомление. Внутри страницы появляется карточка. Свою мелодию можно проиграть только после нажатия «Включить звук и уведомления» или переключателя звука в настройках. Это действие нужно повторять после перезапуска браузера.

Если браузер заморозил вкладку, телефон уснул или приложение закрыто, локальный таймер не гарантирует своевременность. При возврате просроченное событие будет показано. Событие «ежедневно» относится к текущему календарному дню Бишкека.

**Серверный Web Push:** в комплекте есть `/api/push`, `/api/cron` и service worker. После настройки ниже сервер отправит уведомление и без открытой вкладки. Телефон использует свой системный звук: веб-приложение не может гарантированно проиграть загруженную мелодию при закрытой вкладке. Точное время доставки зависит от браузера, сети, энергосбережения и планировщика. Это не будильник с гарантированным временем.

На iPhone Web Push требует совместимой iOS (16.4+) и установки веб-приложения на экран «Домой»; запрос разрешения выполняй из установленного приложения. На Android поддержка зависит от браузера. При запрете разрешения поменяй его в настройках браузера.

## Необязательная настройка фоновых уведомлений

1. Создай Redis-базу Upstash и скопируй REST URL и REST TOKEN.
2. В папке проекта выполни:

   ```bash
   npx web-push generate-vapid-keys
   ```

3. В Vercel → Project → Settings → Environment Variables добавь:

   ```text
   UPSTASH_REDIS_REST_URL=https://your-database.upstash.io
   UPSTASH_REDIS_REST_TOKEN=...
   VAPID_PUBLIC_KEY=...
   VAPID_PRIVATE_KEY=...
   VAPID_SUBJECT=mailto:your-email@example.com
   CRON_SECRET=длинный_случайный_секрет
   ```

   Генерация секрета: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`.
   Никогда не добавляй секреты в клиентские VITE_ переменные и не публикуй .env.
4. Пересобери проект на Vercel.
5. Настрой HTTPS-планировщик, который раз в минуту вызывает `GET https://ТВОЙ-ДОМЕН/api/cron` с заголовком `Authorization: Bearer CRON_SECRET`. Подойдёт планировщик, поддерживающий секретные HTTP-заголовки. Не передавай секрет в URL.
6. Если используешь Vercel Pro и его минутный Cron, добавь в vercel.json поле:

   ```json
   "crons": [{"path": "/api/cron", "schedule": "* * * * *"}]
   ```

   Vercel Hobby не поддерживает минутный cron; поэтому это поле намеренно отсутствует в исходном конфиге и базовая загрузка не блокируется. Для Hobby нужен внешний планировщик. Тарифы и лимиты проверяй у провайдеров.
7. В приложении → Настройки → разреши уведомления → «Подключить» фоновые push. Сделай событие на несколько минут позже и проверь с закрытой вкладкой. Тестируй в Production, где доступен API, не в обычном Vite dev.
8. «Отключить фоновые уведомления» удаляет подписку и её серверное расписание. При изменении событий расписание синхронизируется.

Сервер хранит push-подписку, время и текст событий; расходы, фото и аудио на сервер не отправляются. Устройство получает случайный токен, который хранится в localStorage; сервер использует его хеш. API ограничивает частоту создания подписок и не позволяет просматривать чужие данные. Для публичного массового сервиса нужны пользовательская авторизация, лимиты на инфраструктуре и отдельная политика хранения. Этот комплект предназначен для личного использования.

## Хранение и ограничения

Данные находятся в конкретном браузере и домене, не синхронизируются между телефонами. Очистка сайта, смена браузера/домена или устройство без постоянного хранилища могут удалить записи. Регулярно скачивай резервные копии, особенно перед сменой домена Vercel. Фото сохраняются оригиналами: место ограничено браузером. HEIC может не отображаться в браузерах без поддержки — используй JPEG/PNG/WebP. Не требуется доступ к банковскому счёту.

Карты, погода и Google Fonts загружаются с внешних сервисов. При недоступном шрифте используется системный. Условия OpenStreetMap и Open-Meteo применяются; для большого трафика подключи подходящий коммерческий провайдер тайлов/погоды.

## Проверки и структура

- `npm test` — расчёты, часовой пояс, дедупликация событий, серверное расписание и IndexedDB.
- `npm run test:ui` — интеграционные проверки ввода, редактирования и сохранения в DOM-окружении.
- `npm run build` — production-сборка Vite.

`src/App.jsx` — маршруты и интерфейс; `src/core.js` — время и расчёты; `src/store.js` — IndexedDB и резервные копии; `src/notifications.js` — звук и push-клиент; `src/Map.jsx`, `src/Weather.jsx`, `src/Orbit.jsx` — карта, погода и 3D; `api/` и `server/` — серверные уведомления.

Браузерные разрешения, настоящая камера/GPS, реальная доставка push и внешний прогноз нужно проверить на своём телефоне после публикации. Серверные уведомления не были активированы без твоих ключей и планировщика.
